# React Starter Environment

This project is pre-configured with Vite + React so you can plug in your own component immediately.

## Quick start

```bash
npm install
npm run dev
```

Then open the local URL shown in the terminal.

## Files you will likely edit

- `src/App.jsx` – replace with your component.
- `src/App.css` – component-level styles.
- `src/index.css` – global styles.

## Build for production

```bash
npm run build
npm run preview
```
